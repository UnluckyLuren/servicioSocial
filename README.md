# Proyectos - Servicio Social CUCEI UDG

Repositorio destinado a almacenar y organizar los proyectos desarrollados durante mi servicio social en el **Centro Universitario de Ciencias Exactas e Ingenierías (CUCEI)** de la **Universidad de Guadalajara**.

## 📋 Descripción

Este repositorio reúne el código, documentación y recursos que forman parte de las actividades realizadas en el servicio social. Cada proyecto se encuentra en su propia carpeta para facilitar su consulta.

## 🛠️ Requisitos generales

- Git
- Dependencias específicas indicadas en cada proyecto
- Editor de código de preferencia (VS Code, PyCharm, etc.)
